# 定稿视觉系统 · V2

本文件名沿用旧路径，内容以本 V2 为准。依据：用户于 2026-09-12 明确确认的 3:4、混合字体、编号交替及平台按需展示规则。旧示例中的尺寸或文字不覆盖这些规则。

## 视觉依据与优先级

核心气质：干净的奶油纸教程、珊瑚色刊物标题、真实素材、轻盈文具细节。可读与可信 > 信息层级 > 截图清楚 > 私人风格 > 装饰。

系列名：AI 干中学。系列 slogan：把 AI 学会，把日常做美。
Slogan 可用于新封面或收尾页，不默认重复到每页页眉。

优先级：用户当前要求 > 本 V2 规则 > 定稿参考图的视觉 > 历史概念图。
- `../assets/approved-step1-reference.png`：四步页，参考干净纸感、字体和卡片质感。
- `../assets/approved-step2-reference.png`：上下两步页，参考图文交错。
- 两张参考原尺寸为 4220×5964，约 1:√2，仅保留作视觉证据，不作为新成品尺寸模板。
- 具体菜品、平台、文案、截图和步骤数属于示例内容，不固定到下一期。

## 画布与跨页锚点

- 逻辑画布：1086×1448（严格 3:4）。
- 预览：2172×2896；默认高清 PNG：4344×5792。
- 同一套所有页面共用同一外壳和锚点，导出时文字/布局按 4× 渲染。
- 现有 1086×1448 母版 PNG 的锚点以实际像素为准。旧文档 y=108/1362 只是结构参考，不可据此重复叠画一组横线。
- 新建外壳时先确定唯一坐标表，再跨页复用；建议左右安全边距 56–64px。主内容避开实际页眉/页脚及装饰。
- 迁移旧 1055×1491 教程页时，保留字体、色彩、组件质感，重新安排卡片与图文。不可把整页横向拉伸或纵向压扁成 3:4。
- 高清输出不能提升低分辨率原素材的真实细节；不使用生成模型重绘文字和照片来伪造清晰度。

## 颜色与纸感

- 奶油底：#F6F0E8；卡片：rgba(250,244,237,.72)。
- 主标题珊瑚：#C65F52；正文强调：#C86545。
- 主文字：#292722；正文可用 #38322E；辅助文字：#817872。
- 淡蓝点阵：#BFD4DC，低透明度。
- 胶带用统一低饱和粉色和奶油白波点。
- 每期最多一种额外辅助色，面积克制。
- 纸感清洁、低对比；不把旧图的脏边、密集噪点、灰斑和多层残影当成风格。
- 大片糖果粉、饱和蓝、重黑背景、厚 3D 投影不属于本系列。

## 定稿混合字体

实现参数见 `../assets/approved-style.css`。以下字号都是逻辑画布值；同套页面应统一，不机械压缩以适应容器。

| 用途 | 字体栈 | 基准 |
| --- | --- | --- |
| 页眉 | Songti SC / STSong / Noto Serif CJK SC / serif | 细宋体，21–24px，400，疏朗字距 |
| STEP 整行大标题 | Songti SC / STSong / Times New Roman / serif | 68px，600，珊瑚，行高 1.08 |
| Part 标题 | Songti SC / STSong / serif | 29px，600，深墨，行高 1.3 |
| 引导句 | Kaiti SC / STKaiti / Songti SC / serif | 22px，400，行高 1.5 |
| 彩色短提示 | Kaiti SC / STKaiti / serif | 25px，600，行高 1.35 |
| 操作正文 | PingFang SC / Hiragino Sans GB / Microsoft YaHei / sans-serif | 20px 起，400，行高 1.65 |
| 短指令/提示框 | Kaiti SC / STKaiti / Songti SC / serif | 18–20px，行高 1.58 |
| 辅助说明 | 正文无衬线栈 | 17–18px，灰棕，行高 1.55 |
| 页码 | Times New Roman / Songti SC / serif | 24px，斜体，珊瑚 |

已核对的历史定稿操作正文为 17.5–18px；新 3:4 排版以 20px 为可读性起点，必要时拆页，不把所有历史小字尺寸原样照搬。

- STEP 数字、中文动作标题、skill 等英文词共用同一标题类、字号、字重、颜色与基线。
- 保持字形自然宽度。禁止 Condensed/Narrow、scaleX(<1) 和负字距塞文案。
- 溢出顺序：换行 → 调整可用宽度 → 拆页或在获准情况下精简 → 小幅减字号。
- 缺少指定字体时先查本地可用字体，选择相同类别近似字体并目检；不可把混合系统全部退化成无衬线。
- 页眉左侧不放大实心星；已有母版页眉尽量直接复用。

## 组件与图文节奏

- Part：18px 轻圆角、约 1.2px 淡珊瑚边；整体上沿及侧边内嵌阴影、中央略亮，极轻外投影托底。
- 图片：保持原比例完整显示，默认 10px 轻圆角，柔和阴影。透明抠图投影跟随轮廓；不新增白色相框。
- 编号：使用固定 01–04 PNG，基准 76×76，保持正圆。
- 按本页步骤顺序，编号在左/右/左/右交替；2 步左右，3 步左右左，4 步左右左右。编号靠近 Part 上沿，给标题留出独立空间。
- 上下步骤优先左图右字、左字右图交错；四步 2×2 内部根据素材比例安排，不为交错牺牲可读性。
- 只加与操作直接相关的小标注，如指向确切对象的一个“＋”；不随意追加箭头或圈选。
- 波点胶带、星星、蝴蝶结、花枝每页最多选 1–2 类主要装饰；母版已有装饰计入总量。胶带要压住实际图片边缘，不能无意义悬空。
