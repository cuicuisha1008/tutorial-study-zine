# 交付验收

## 规格与系列

- [ ] 逻辑画布 1086×1448；最终 PNG 4344×5792；可选预览 2172×2896，均严格 3:4。
- [ ] 同套页面尺寸一致，页眉、横线、边距、页码基线不跳；没有重复叠画页脚横线。
- [ ] 旧 1055×1491 页面只作为视觉参考，新版重排而非整页拉伸。
- [ ] 原素材清晰度如实保留，没有把位图放大冒充新增细节。

## 内容与素材

- [ ] 用户文案及截图中的界面文字正确，每一步匹配正确原图。
- [ ] 原图保持比例、方向、页数、结构及完整主体；无重绘、生成补画、误裁或拉长。
- [ ] 抠图没有误删书页、装订环或文字；无需抠图的整张照片保持完整。
- [ ] 平台名称/Logo/网址是否显示符合当期要求，未机械隐藏或强制展示。
- [ ] 封面收益与正文对应；没有编造数据、效果承诺或未提供的词典。
- [ ] Slogan 如使用，逐字为“把 AI 学会，把日常做美。”；没有强塞到每页。

## 字体与布局

- [ ] 页眉细宋体，STEP 和 Part 标题宋体，引导/短提示楷体，操作正文无衬线。
- [ ] STEP 数字、中文、英文使用同一标题系统；同层级字体参数一致。
- [ ] 字形未压窄，无负字距塞文案；手机预览中正文可读。
- [ ] 2 步左右，3 步左右左，4 步左右左右；使用固定纽扣资产。
- [ ] 内嵌阴影作用于整个 Part；图片轻圆角、柔和阴影，没有新增粗边或白框。
- [ ] 图文留白充分，无出框、遮挡、错误断行或页脚截断。
- [ ] 纸感干净，无旧版脏边与过量颗粒；装饰克制且位置有意义。

## 修改范围与导出

- [ ] 局部修改与指定区域相符，冻结区域保持不变。
- [ ] 旧文字、旧图片及投影完全清除，无残影、旧边或双层重叠。
- [ ] 若概念稿生成了错误素材，已清空错误区域并直贴原文件。
- [ ] 动态扩展检查首、中、末帧，确认移动主体不露底、不撞边；静态页无须做此检查。
- [ ] 2× 预览已目检，4× 成品尺寸已验证；无透明破洞、意外白边或水印。
- [ ] 按 page-01.png 等连续命名，保留可编辑源文件与必要引用素材。
- [ ] 源图缺失时只交明确标注的草稿，占位图不算最终交付。
